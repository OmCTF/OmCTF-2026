# Native preview collision

The script classifies attachment UUIDs from the current flat attack-data,
finds a public-file name with the same 20-bit native cache key as each target
UUID, and creates its own Public file under a recent published intake. A
normal preview of the owned file can receive cached bytes of the foreign
Internal attachment. It does not use direct foreign download access.

The name collision is computed with a bounded meet-in-the-middle search.
Public intake enumeration and candidate areas dominate runtime; separate
ordinary accounts and concurrent workers keep writes within per-account
quotas. The script prints only exact flag-shaped preview bodies.

Live tests on 2026-11-02 recovered 6 current flags in 35-43 seconds,
including concurrent runs. Network load may still exceed a tight farm
timeout.
