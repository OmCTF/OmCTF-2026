# Казна: правила SDK для C++20

Подключите [`include/kazna.hpp`](include/kazna.hpp) и реализуйте две функции
в `namespace kazna::sdk`:

```cpp
std::vector<Recruit> deploy(const DeploymentContext &context);
std::vector<Command> decide(const Observation &observation);
```

`deploy` набирает до 20 бойцов на трёх постах и укладывается в бюджет.
Функция получает правила эпохи и зерно боя, но ещё не видит карту. `decide`
вызывается каждый ход. В `observation` есть карта, свои бойцы и замеченные
враги. Позиции скрытых врагов и чужих мин программа не получает.

За раунд каждая пара команд проводит два боя, по одному в каждом направлении. Итоговая оценка даёт от нуля до трёх
флагов. Исходный код налёта и обороны остаётся закрытым для соперников.
Рабочие заготовки: [налёт](examples/raider.cpp) и
[стража](examples/guard.cpp).

## Бойцы

| Тип в коде | Роль |
| --- | --- |
| `Blade` | Рубака. Дешёвый боец ближнего боя. |
| `Shield` | Щитоносец. Держит удар и умеет укрепляться. |
| `Archer` | Лучник. Стреляет на ходу, может подавлять врага. |
| `Rider` | Всадник. Быстро заходит с фланга; копейщики опасны для него. |
| `Sapper` | Сапёр. Закладывает заряды у казны и ставит мины. |
| `Scout` | Разведчик. Дальше видит, быстрее идёт и ставит дым. |
| `Pike` | Копейщик. Удерживает ворота и встречает всадников. |
| `Crossbow` | Арбалетчик. Бьёт далеко и сильно, но тратит болты и перезаряжается. |
| `Medic` | Лекарь. Лечит бойцов рядом и снимает подавление. |
| `Engineer` | Инженер. Строит баррикады, ставит мины и чинит казну. |
| `Alchemist` | Алхимик. Стреляет на короткой дистанции и ставит дым. |
| `Herald` | Глашатай. Поднимает боевой дух и снимает подавление. |

Цена, здоровье, урон и скорость каждого типа записаны в `rules`. Там же
лежат бюджеты, запасы, броня казны, погода, число ходов и ключ карты.
По умолчанию эпоха длится три раунда, а следующая объявляется за три
раунда до начала. Фактическое расписание определяют настройки задачи.
`GET /api/v1/arena/treasury/rules` возвращает правила и их интервалы
действия. В трансляции текущие и следующие правила находятся на вкладках
«Сейчас» и «Объявлены».

У бойца есть здоровье, выносливость, боевой дух, боезапас, перезарядка,
щит и подавление. Эти поля доступны в `observation.units`. Уставший или
подавленный боец бьёт слабее. Стрелок расходует боеприпасы.

## Приказы

Команда записывается как `Command{unit_id, action, target_id, target_x,
target_y}`. Последние три поля по умолчанию равны `-1`. Для `Focus` и
`Suppress` можно указать ID видимого врага, для `Heal` — ID союзника.
Приказам движения можно задать точку. Если её нет, налётчик идёт к казне,
а страж ищет ближайшего налётчика. Боец с добычей сам возвращается к своему
посту.

| Приказ | Что делает |
| --- | --- |
| `Advance` | Идёт к цели и атакует врага в пределах досягаемости. |
| `Hold` | Стоит на месте, восстанавливает выносливость и атакует рядом. |
| `Focus` | Идёт к замеченному врагу и атакует его. |
| `Retreat` | Возвращается на свой пост. |
| `Breach` | Сапёр рядом с казной закладывает заряд. Тратит два запаса. |
| `Scout` | Идёт к цели; разведчик получает дополнительный шаг. |
| `Fortify` | Щитоносец, копейщик или инженер укрепляется. Инженер может поставить баррикаду. |
| `Repair` | Инженер стражи у казны обезвреживает заряд или чинит хранилище. |
| `Heal` | Лекарь восстанавливает союзнику до шести единиц здоровья. |
| `Suppress` | Стрелок наносит меньше урона, зато подавляет цель. |
| `Smoke` | Разведчик или алхимик ставит дымовую завесу. |
| `Rally` | Глашатай поднимает боевой дух союзников рядом. |
| `Dash` | Боец проходит на два шага дальше, тратит выносливость и не атакует. |
| `PlantMine` | Сапёр или инженер ставит скрытую мину на своей клетке. |

Поддержка расходует общий запас команды и обычно требует перезарядки.
Неверный приказ пропускает ход бойца. Если названный враг не виден, `Focus`
и `Suppress` не сработают.

## Карта и видимость

`Observation::terrain` содержит 384 символа: карта 24 × 16, строки идут
подряд. Для отдельной клетки используйте `observation.tile(x, y)`.

| Знак | Клетка |
| --- | --- |
| `.` | Обычная земля |
| `:` | Грязь, замедляет |
| `%` | Развалины, замедляют и дают укрытие |
| `~` | Вода Иртыша, пройти нельзя |
| `=` | Мост |
| `#` | Стена, преграждает путь и обзор |
| `+` | Ворота |
| `$` | Казна |
| `B` | Баррикада инженера, замедляет и укрывает |
| `m` | Своя мина |

Зерно пары команд меняет мосты, ворота и укрытия от боя к бою. Внутри боя
карта сохраняется; инженеры могут добавить баррикады. Жюри само строит
маршрут приказов движения через проходимые клетки. Погода и дым сокращают
обзор. Чужие мины скрыты, свои помечены буквой `m`.

Жюри принимает исходник C++20 размером до 16 КиБ. Программа запускается
с ограничениями по процессору, памяти, файлам и сети. Порядок отправки
описан в [инструкции команды](README.md). Запись боя содержит публичные
действия, но не содержит исходный код или флаги.
