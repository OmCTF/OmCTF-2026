Place `developer-credentials.txt` here before the first `docker compose up`.
The file must contain exactly two lines: the developer.1c.ru login and password.
Do not add quotes, keys, or a third line. Windows CRLF line endings are accepted.
The onec container removes the file after one activation attempt, whether it
succeeds or fails. Only this directory is mounted read-write for this purpose.
The Community License agreement is accepted automatically only when the known
agreement page and button are recognized. A new host still needs an eligible
developer account and its own valid license activation.
