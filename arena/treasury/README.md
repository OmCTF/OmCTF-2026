# Казна для Skipper Arena

Пакет целиком находится в этом каталоге. Skipper читает `arena.yml`, а adctl собирает рефери из `Dockerfile` с этим каталогом в качестве контекста. Рефери принимает задачи от Skipper по внутреннему протоколу `arena/v1`.

| Файл | Назначение |
| --- | --- |
| `arena.yml` | Роли, правила, расписание, лимиты и политика начисления |
| `backend/` | Симуляция боя, генерация правил, компилятор и песочница |
| `defaults/guard.cpp` | Оборона, которую рефери использует при отсутствии заявки |
| `participants.yml` | Файлы, которые adctl выдаёт командам |
| `sdk/` | Комплект участника с описанием правил и примерами |
| `terminal/` | Дополнительный шлюз для команд, использующих nc |
| `frontend/` | Дополнительная трансляция боёв через публичный API Skipper |
| `compose.yml` | Локальный запуск рефери для проверки контракта |

Роль `raider` атакует роль `guard`. Каждая команда встречается в обоих направлениях с каждой другой. Рефери возвращает до трёх захватов за налёт. Skipper хранит результаты и применяет выбранную политику начисления.

Рефери запускается локально через `docker compose -f compose.yml up --build`. Участники получают [SDK и примеры](sdk/README.md).
